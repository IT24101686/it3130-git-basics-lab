# IT3130 Git Basics Lab
## Purpose
This repository demonstrates a basic Git workflow for IT3130.
## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation
## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
In this lab, I learned how to use the staging area to prepare my modified files before permanently recording them as commits in the local repository. Furthermore, I understood how to connect this local repository to a remote GitHub repository to push my code and maintain a secure online backup.
